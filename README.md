# 한줄 입력 (OneLine)

맥 메뉴 막대에 사는 작은 앱입니다. `내일 3시 치과`처럼 한 줄만 쓰면 **캘린더 일정과 미리알림을 한 번에** 만들어 줍니다.
캘린더 따로, 미리알림 따로 두 번 적는 게 귀찮아서 만들었습니다.

## 사용법

1. `⌥Space`를 누르면 화면 가운데 입력창이 뜹니다. (다른 앱이 이미 쓰고 있으면 `⌃⌥Space`)
2. 한 줄로 입력합니다. 아래 미리보기에 날짜와 시간이 어떻게 읽혔는지 바로 보입니다.
3. `⏎`를 누르면 저장되고 창이 닫힙니다.

| 키 | 동작 |
|---|---|
| `⏎` | 추가 |
| `⇥` (Tab) | 종류 바꾸기: 둘 다 → 일정만 → 미리알림만 |
| `esc` | 닫기 |

### 무엇을 만들지 자동으로 정합니다

| 입력 | 결과 |
|---|---|
| `내일 3시 치과` | 일정 (오후 3시~4시) + 미리알림 (10분 전 알림) |
| `다음주 월 10시~12시 회의` | 2시간짜리 일정 + 미리알림 |
| `금요일까지 보고서 제출` | 미리알림만 (금요일 마감) |
| `우유 사기` | 미리알림만 |
| `매주 월수금 7시 헬스 12월까지` | 반복 일정 + 반복 미리알림 (12월 31일까지) |
| `매달 25일 월세` | 반복 미리알림 |
| `11월 20일~22일 제주 여행` | 3일짜리 하루 종일 일정 |

시간이 있으면 둘 다, 여러 날 기간이면 일정만, 나머지는 미리알림만 만듭니다. 틀리면 `Tab`으로 바꾸면 됩니다.

### 읽을 수 있는 표현

- 날짜: `오늘`, `내일`, `모레`, `글피`, `금요일`, `이번주 금`, `다음주 월`, `다다음주 수요일`, `11월 20일`, `12/25`, `25일`, `3일 뒤`
- 시간: `3시`, `3시 반`, `오후 2시 30분`, `15:30`, `아침 9시`, `저녁 8시`, `밤 12시`
- 범위: `10시~12시`, `밤 11시~1시` (자정을 넘기면 다음 날로)
- 반복: `매일`, `3일마다`, `매주 월수금`, `화목마다`, `격주 금`, `2주마다 토`, `평일마다`, `매 주말`, `매달`, `격월`, `매년`
- 반복 끝: `12월까지`, `12월 31일까지`, `올해까지`, `10번`
- 여러 날: `11월 20일~22일`, `12/24~12/26`, `12/30~1/2`, `금~일`, `다음주 월~수`, `내일부터 2박 3일`, `모레부터 5일간`
- 오전/오후를 안 쓰면 1~7시는 오후로 봅니다 (`3시 치과` → 오후 3시).

## 설정

메뉴 막대 아이콘 → **설정…**

- 일정을 넣을 캘린더 (구글 캘린더도 가능)
- 미리알림을 넣을 목록
- 알림 시점: 정각 / 10분 전 / 30분 전 / 1시간 전
- 로그인할 때 자동으로 켜기 (처음 실행할 때 켜집니다)

**구글 캘린더를 쓰려면** 시스템 설정 → 인터넷 계정 → Google에서 계정을 추가하고 캘린더를 켜 주세요. 그러면 설정 목록에 나타납니다.

## 바탕화면 위젯

> 직접 빌드한 앱에서만 일정이 나옵니다 (아래 설치 방법 2).

맥 캘린더에 있는 일정(구글 캘린더 포함)을 달력으로 보여주는 위젯이 있습니다.

- **큰 크기**: 한 달
- **중간 크기**: 이번 주와 다음 주
- 오른쪽 위 **＋**를 누르면 입력창이 열리고, 나머지를 누르면 캘린더 앱이 열립니다.
- 앱이 맥 캘린더를 직접 읽기 때문에, 구글 서버와 동기화되기 전에도 넣은 일정이 바로 보입니다.

바탕화면 빈 곳 우클릭 → **위젯 편집** → **한줄 달력**을 골라 바탕화면에 끌어다 놓으세요.

> 위젯은 앱과 데이터를 나누기 위해 **애플 계정 팀으로 서명**해야 합니다 (무료 계정도 됩니다). `Config/Local.xcconfig` 파일을 만들고 아래처럼 자기 팀 ID를 넣은 뒤 빌드하세요. 팀 ID는 Xcode → 설정 → Accounts에서 볼 수 있습니다. 이 파일은 깃에 올라가지 않습니다.
>
> ```
> DEVELOPMENT_TEAM = ABCDE12345
> CODE_SIGN_IDENTITY = Apple Development
> ```
>
> 이 파일이 없으면 애드혹 서명으로 빌드되고, 입력창은 그대로 쓸 수 있지만 위젯에는 일정이 나오지 않습니다.

## 설치

macOS 14 (Sonoma) 이상에서 동작합니다. Apple Silicon과 Intel 맥 모두 됩니다.

### 방법 1. 내려받아 바로 쓰기 (쉬움)

1. [Releases](https://github.com/door-yeah/oneline/releases/latest)에서 **OneLine.zip**을 내려받습니다.
2. 압축을 풀고 나온 **OneLine**을 **응용 프로그램** 폴더로 옮깁니다.
3. OneLine을 더블클릭합니다. 처음에는 *"Apple은 'OneLine'에 … 악성 코드가 없음을 확인할 수 없습니다"* 같은 경고가 뜹니다. **완료**(또는 취소)를 누르세요.
4. **시스템 설정 → 개인정보 보호 및 보안**으로 가서 아래쪽의 *"'OneLine'이(가) 차단되었습니다"* 옆 **그래도 열기**를 누릅니다. 맥 암호를 넣으면 열립니다.
5. 캘린더와 미리알림 접근 권한을 물어보면 둘 다 **허용**합니다.

이후에는 경고 없이 열립니다. 메뉴 막대에 아이콘이 생기고, **⌥Space**로 입력창을 엽니다.

> **왜 경고가 뜨나요?** 이 앱은 개인이 만든 무료 앱이라 애플의 유료 공증을 받지 않았습니다. 코드는 이 저장소에 모두 공개되어 있습니다.
>
> 4번에 **그래도 열기**가 보이지 않으면 터미널에서 아래 명령을 한 번 실행한 뒤 다시 열어 보세요.
>
> ```bash
> xattr -dr com.apple.quarantine /Applications/OneLine.app
> ```

> 내려받은 앱에서는 **바탕화면 위젯에 일정이 나오지 않습니다.** 입력창은 그대로 다 됩니다. 위젯까지 쓰려면 아래 방법 2로 직접 빌드하세요.

### 방법 2. 직접 빌드하기 (Xcode 필요, 위젯까지)

```bash
git clone https://github.com/door-yeah/oneline.git
cd oneline
xcodebuild -project OneLine.xcodeproj -scheme OneLine -configuration Release -derivedDataPath build
cp -R build/Build/Products/Release/OneLine.app /Applications/
open /Applications/OneLine.app
```

또는 Xcode에서 `OneLine.xcodeproj`를 열고 ▶ 버튼을 누르세요. 위젯까지 쓰려면 빌드하기 전에 위의 **바탕화면 위젯** 항목대로 `Config/Local.xcconfig`를 만들어 주세요.

처음 실행하면 캘린더와 미리알림 접근 권한을 물어봅니다. 둘 다 허용해 주세요.

> 애플 계정 팀 없이 빌드하면, 다시 빌드할 때 권한을 다시 물어볼 수 있습니다.

## 한계

- 타임트리처럼 공개 API가 없는 캘린더 서비스에는 넣을 수 없습니다. 맥 캘린더 앱에 연결되는 캘린더(iCloud, Google, Exchange 등)만 됩니다.
- `매달 마지막 금요일`, `매달 둘째 주 화요일` 같은 반복은 아직 읽지 못합니다.

## 구조

| 파일 | 역할 |
|---|---|
| `KoreanDateParser.swift` | 한국어 문장에서 날짜·시간·반복·기간 읽기 |
| `Recurrence.swift` | 반복 규칙 |
| `CalendarService.swift` | 캘린더·미리알림 저장 (EventKit) |
| `InputPanel.swift` | 입력창 띄우고 닫기 |
| `InputView.swift` | 입력창 화면 |
| `SettingsView.swift` | 설정 화면 |
| `HotKey.swift` | 전역 단축키 |
| `OneLineApp.swift` | 앱 시작, 메뉴 막대 아이콘 |
| `WidgetSync.swift` | 위젯에 보여줄 일정을 공유 폴더에 써 두기 |
| `OneLineWidget/` | 바탕화면 달력 위젯 |
| `Shared/` | 앱과 위젯이 함께 쓰는 코드 |
| `Config/` | 서명·Info.plist·권한 설정 |
