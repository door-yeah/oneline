# 한줄 입력 (OneLine)

맥 메뉴 막대에 사는 작은 앱입니다. `내일 3시 치과`처럼 한 줄만 쓰면 **캘린더 일정과 미리알림을 한 번에** 만들어 줍니다.
캘린더 따로, 미리알림 따로 두 번 적는 게 귀찮아서 만들었습니다.

## 사용법

1. `⌥Space`를 누르면 화면 가운데 입력창이 뜹니다. (다른 앱이 이미 쓰고 있으면 `⌃⌥Space`)
2. 한 줄로 입력합니다. 아래 미리보기에 날짜와 시간이 어떻게 읽혔는지 바로 보입니다.
3. `⏎`를 누르면 저장되고 창이 닫힙니다.

| 키 | 동작 |
|---|---|
| `⏎` | 추가 |
| `⇥` (Tab) | 종류 바꾸기: 둘 다 → 일정만 → 미리알림만 |
| `esc` | 닫기 |

### 무엇을 만들지 자동으로 정합니다

| 입력 | 결과 |
|---|---|
| `내일 3시 치과` | 일정 (오후 3시~4시) + 미리알림 (10분 전 알림) |
| `다음주 월 10시~12시 회의` | 2시간짜리 일정 + 미리알림 |
| `금요일까지 보고서 제출` | 미리알림만 (금요일 마감) |
| `우유 사기` | 미리알림만 |
| `매주 월수금 7시 헬스 12월까지` | 반복 일정 + 반복 미리알림 (12월 31일까지) |
| `매달 25일 월세` | 반복 미리알림 |
| `11월 20일~22일 제주 여행` | 3일짜리 하루 종일 일정 |

시간이 있으면 둘 다, 여러 날 기간이면 일정만, 나머지는 미리알림만 만듭니다. 틀리면 `Tab`으로 바꾸면 됩니다.

### 읽을 수 있는 표현

- 날짜: `오늘`, `내일`, `모레`, `글피`, `금요일`, `이번주 금`, `다음주 월`, `다다음주 수요일`, `11월 20일`, `12/25`, `25일`, `3일 뒤`
- 시간: `3시`, `3시 반`, `오후 2시 30분`, `15:30`, `아침 9시`, `저녁 8시`, `밤 12시`
- 범위: `10시~12시`, `밤 11시~1시` (자정을 넘기면 다음 날로)
- 반복: `매일`, `3일마다`, `매주 월수금`, `화목마다`, `격주 금`, `2주마다 토`, `평일마다`, `매 주말`, `매달`, `격월`, `매년`
- 반복 끝: `12월까지`, `12월 31일까지`, `올해까지`, `10번`
- 여러 날: `11월 20일~22일`, `12/24~12/26`, `12/30~1/2`, `금~일`, `다음주 월~수`, `내일부터 2박 3일`, `모레부터 5일간`
- 오전/오후를 안 쓰면 1~7시는 오후로 봅니다 (`3시 치과` → 오후 3시).

## 설정

메뉴 막대 아이콘 → **설정…**

- 일정을 넣을 캘린더 (구글 캘린더도 가능)
- 미리알림을 넣을 목록
- 알림 시점: 정각 / 10분 전 / 30분 전 / 1시간 전
- 로그인할 때 자동으로 켜기 (처음 실행할 때 켜집니다)

**구글 캘린더를 쓰려면** 시스템 설정 → 인터넷 계정 → Google에서 계정을 추가하고 캘린더를 켜 주세요. 그러면 설정 목록에 나타납니다.

## 설치

macOS 14 (Sonoma) 이상과 Xcode가 필요합니다.

```bash
git clone https://github.com/door-yeah/oneline.git
cd oneline
xcodebuild -project OneLine.xcodeproj -scheme OneLine -configuration Release -derivedDataPath build
cp -R build/Build/Products/Release/OneLine.app /Applications/
open /Applications/OneLine.app
```

또는 Xcode에서 `OneLine.xcodeproj`를 열고 ▶ 버튼을 누르세요.

처음 실행하면 캘린더와 미리알림 접근 권한을 물어봅니다. 둘 다 허용해 주세요.

> 개발자 서명 없이 빌드하기 때문에, 다시 빌드하면 권한을 다시 물어볼 수 있습니다.
